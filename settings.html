记忆中枢

v6.13.1

透明记忆网关：把经过 Magpie 的对话沉淀为长期记忆，并通过 MCP 供 agent 检索；内置踩坑库、上下文压缩、R2 存储。

💡 使用说明（快速上手三步） 查看指南
1
填 MCP Key 与数据库名 在下方「NoCodeBackend 数据库与密钥」卡片中填入 MCP Key（可在 NCB 后台 Developer 页面获取）与数据库名（推荐保持 memory）。
2
点击「一键创建数据库」 点击「一键创建数据库与结构」，插件自动完成数据库、三张核心表、字段与唯一索引创建，并自动回填保存数据库密钥。
3
完成并开始使用 主路径即刻就绪，所有 agent 均可通过 MCP 检索与沉淀长期记忆。可选：挂载 Cloudflare R2 存储或下载本地离线小模型；其余设置项均自带生产级推荐值，保持默认即可。
⚠️ 未完成配置：请填写下方 MCP Key 与数据库名称，然后点击「一键创建数据库」

记忆采集来源 网关异步自动记忆 · 对话录制离线扫描备选 · 零模型开销
路径一 自动记忆 推荐

由网关直接提供对话，不需要开启 Magpie 内置的「记录网关对话」，不占磁盘。开关是 auto_harvest。

路径二 扫描对话录制 备选

读 Magpie 内置录制，需要先在「设置 → 插件 →「会话」」里开启录制（会占用本地磁盘，官方上限 7 天 / 256 MiB）。对应「立即扫描对话录制」按钮。

推荐 关
开启后网关上每次模型交互都会由异步钩子自动提炼事实、架构决策与避坑经验入库，零云端模型成本，不占磁盘。
开：网关上每次模型交互都会被提炼入库；关（默认）：关闭自动记忆，关闭则零影响。

📦 备选路径：扫描对话录制（依赖本地磁盘落盘）

若需使用此备选路径扫描本地录制，需先在 Magpie 里开启对话录制：
打开 设置 → 插件，找到内置插件 「会话」 把它打开（开关位于插件页中该插件的说明文字旁）。
打开后该插件会显示 「正在记录网关对话」；其说明文字为 「已开启：Agent 经网关发送的内容和回复只保存在这台电脑上，最多 7 天（256 MiB），可在每个网关会话下查看」。
若要关闭录制，点 「停止记录并清空已保存的对话」。
—— 插件本页只是读取该录制的结果，无法代你开启，需先去那里打开。若使用上方的推荐方案「自动记忆」，则完全无需开启此录制功能。

本地落盘与隐私保护说明：
1. 开启录制意味着对话内容会写到本地磁盘（/config/magpie/gateway-conversations，受官方 7 天 / 256 MiB 配额限制）。
2. 插件只把提炼后的结构化记忆入库，绝不把对话原文入库；提炼采用本地规则引擎，无任何外部云端调用。
3. 若未开启录制或暂无录制文件，点击扫描将显示友好提示，不会报错。

记忆提炼与入库门槛 内联免模型提炼 · 候选记忆入库置信度门槛
推荐 开
让正在对话的当前模型在回复末尾通过特定格式顺手产出记忆，零外部模型调用。
开：零模型免额外 API 成本，提炼随对话顺手完成；关：彻底关闭自动提炼，仅依赖手动录入或外部工具。
推荐 0.6
提炼出的候选记忆写入数据库的最低评分门槛（取值范围 0~1）。
调高（如 0.8+）：记忆入库更严苛、数据更干净，但可能遗漏细节；调低（如 0.4）：采集更全面，但容易混入琐碎噪声。
网关注入与上下文预算 准则置顶 · CCR 摘要卡 · 字符预算与注入条数限制
推荐 开
在向当前会话注入相关记忆时，同步注入历史踩坑记录与行为准则。
开：遇到相似场景主动提示过往避坑经验，避免重复踩坑；关：只注入普通事实记忆，略微精简上下文。
推荐 关
超过 160 字的长记忆只向上下文注入「摘要 + id」，完整内容按需动态展开。
开：大幅节省提示词 Token，但 Agent 需额外调用 memory_get 展开；关：一次性注入完整记忆全文，Token 消耗较大。
推荐 5
单次请求注入到系统上下文中的相关事实记忆最大数量。
调大：检索注入的记忆参考面更广，但占用提示词空间；调小：严格精简上下文，只保留最强相关的少数条目。
推荐 2048
单次请求注入的所有记忆与踩坑规则允许占用的字符总上限。
调大：允许注入更长更详细的记忆内容；调小：超出预算时自动截断或丢弃低分项，防止挤占模型上下文。
推荐 2
单次请求注入到上下文中的避坑与原则规则最大数量。
调大：覆盖更多相关的避坑教训；调小：仅提示权重最高的核心规则，防止过多规则分散模型注意力。
推荐 关
全局一键暂停记忆向提示词的注入功能。
开：彻底暂停所有记忆和避坑注入，网关仅直通原始提示词；关：正常启用记忆检索与上下文增强。
上下文压缩与去重 历史工具输出压缩 · 跨轮文件指纹去重 · 本地小模型
推荐 开
压掉历史消息中冗余的工具调用输出与过长文本块（绝不动 system prompt 与最后一条用户消息）。
开：显著节省 Token 与推理成本，但历史消息的中间调试过程会被折叠；关：上下文原样完整保留，费用更高。
推荐 开
Agent 反复重显同一文件或工具输出时折成指针，只回指更早轮次（前缀缓存不失效）。
开：消除长会话中重复出现的工具输出，避免上下文暴涨；关：每次工具返回均保留独立副本。
离线语义压缩固定使用本地多语言小模型 LLMLingua-2 XLM-RoBERTa-large INT8（约 552MB，560M 参数，原生支持中文与中英混合长文本），纯 CPU 本地推理，不联网、不上传数据。
可点击下方按钮检测本地模型环境与权重文件是否就绪。
推荐 3000
单个工具输出或历史文本块压缩后允许保留的最大字符数。
调大：保留更完整的单次工具输出细节；调小：对超大块输出施加更激进的截断与提炼，节省空间。
推荐 1200
触发离线文本压缩的最小字符数阈值，短于此值的块保持原样。
调大：短小和中等输出绝不压缩，保护完整性；调小：较短文本也会参与轻度规整与去噪。

确认一键创建数据库

将向宿主提交一键创建信标，自动执行以下操作：

  • 自动在 NoCodeBackend 上创建数据库（若不存在）
  • 自动补齐缺失的数据表（memories、pitfalls、schema_meta）、列与索引
  • 若同名已存在不会破坏数据：将走复用/补齐策略，绝不删除已有数据
  • 不会动 R2 存储（如需挂载 R2，请在下方 R2 卡片单独点击「挂载 R2 存储」）
  • 新建库时自动保存密钥：若本次新建数据库，将保存 NCB 仅在建库时返回一次的 Secret Key；复用已有库则无法读取，须手动填入

⚠️ 确认清空数据库

将删除 memories / pitfalls / schema_meta 三张表，表结构与全部数据一并删除，不可恢复；库中其它表不受影响。
