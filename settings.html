🧠 记忆中枢与 MCP 控制台 v1.5.0

网关前置注入控制、动态模型提炼流水线、NoCodeBackend 存储与一键 MCP 导出。

1. 网关前置无感注入 (Gateway Interception)

启用记忆自动注入 (Auto-Injection)
拦截用户 Prompt 并在路由前自动注入匹配的架构经验与开发规范
注入避坑警示 (Engineering Pitfalls)
当识别到匹配的技术栈时，自动前置注入历史上记录的故障根因与修复解
版本更替淘汰 (Auto Supersede)
当写入同一主题的新经验时，自动将旧记录标记为 superseded 淘汰

2. 记忆提炼与 Clef 仲裁模型 (Learner & Clef Pipeline)

后台对话收尾后自动提炼事实并由 Clef 进行质量裁决。支持从下方下拉建议中点选，也可直接输入你在网关配置的任意模型名称。

建议使用成本低、响应极快的小模型
负责甄别高价值经验、过滤临时废话

3. MCP 服务一键挂载 (Model Context Protocol)

复制此配置即可一键挂载到 Cursor、Claude Desktop、Cline 或 Minis，使外部 Agent 具备主动调取与沉淀记忆的能力。

关键参数名 当前配置值 说明
server_name magpie-memory-hub MCP 服务注册唯一名称标识
command python3 系统 Python 3 运行时环境
args ["/path/to/daemon.py", "--mcp"] 标准 Stdio JSON-RPC 启动参数
NCB_INSTANCE 41694_agent_core_hub NoCodeBackend 终态核心数据库实例
NCB_SECRET_KEY 已安全加载 数据库端点安全凭证 (Server Secret Key)
