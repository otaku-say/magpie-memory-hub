记忆中枢

把经过 Magpie 的对话沉淀为长期记忆，并通过 MCP 供所有 agent 取用。

数据库

要创建或连接的数据库名称。填逻辑名即可（如 memory），NoCodeBackend 会自动添加账号前缀，实际在后台形如 41694_memory。

数据库本身的 Secret Key。若由本插件创建数据库，宿主会自动取得并写回保存，无需手填。

提炼模型

模型 ID 手动填写，插件不内置任何模型。

规则仲裁用「置信度阈值 + 信息量 + 与既有记忆的相似度」判断，不花任何模型调用。

上下文压缩

压掉历史里的工具输出与超长文本，保住报错与关键行。 绝不动 system prompt 与最后一条用户消息。

网关注入

按提问关键词挑选相关记忆，注入 system prompt。

数据库管理

只需填写 MCP Key，即可一键全自动建库、建表、挂载存储与迁移。

建库/建表/挂载存储需要 MCP Key（在 NoCodeBackend 后台 Developer 页面获取）。这是全自动管理数据库唯一必需填写的凭据。

NoCodeBackend 遇到重名不会报错而是静默加后缀（例如请求 memhub 已存在时会建成 41694_memhub_1），导致数据被劈成两半。复用已有库（reuse）会复用同名库并集中数据；自动加后缀（auto_rename）会新建一个互不相通的独立库。

Cloudflare R2 对象存储配置 可选 · 全部留空即可自动复用

用于大文件与记忆附件的多模态持久存储。账号若在 NoCodeBackend 中已有 Cloudflare 连接会自动复用，以上字段均可留空。

MCP 接入地址

在 资源库 → MCP 服务器 里添加该地址并勾选要启用的 agent，Magpie 会自动写进各 agent 的配置，无需手工改配置文件。

地址生效需要两个前提：设置 → 插件 中开启内置的 Plugin tools，且本插件处于启用状态。

工具名形如 magpie-memory-hub_memory_search。

确认一键创建数据库

将向宿主提交一键创建信标，自动执行以下操作：

  • 自动在 NoCodeBackend 上创建数据库（若不存在）
  • 自动补齐缺失的数据表（memories、pitfalls、memhub_meta）、列与索引
  • 若同名已存在不会破坏数据：将走复用/补齐策略，绝不删除已有数据
  • 按配置自动创建或挂载 Cloudflare R2 存储桶并配置 CORS
  • 自动提取并保存数据库的 Secret Key，后续无需手填

⚠️ 确认清空数据库

将删除 memories / pitfalls / memhub_meta 三张表，表结构与全部数据一并删除，不可恢复；库中其它表不受影响。
