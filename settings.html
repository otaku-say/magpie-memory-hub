记忆中枢

v6.30.2

透明记忆网关：把经过 Magpie 的对话沉淀为长期记忆，并通过 MCP 供 agent 检索；内置踩坑库、R2 存储。

💡 使用说明（快速上手三步） 查看指南
1
填 MCP Key 与数据库名 在下方「NoCodeBackend 数据库与密钥」卡片中填入 MCP Key（可在 NCB 后台 Developer 页面获取）与数据库名（推荐保持 memory）。
2
点击「一键创建数据库」 点击「一键创建数据库与结构」，插件自动完成数据库、三张核心表、字段与唯一索引创建，并自动回填保存数据库密钥。
3
完成并开始使用 主路径即刻就绪，所有 agent 均可通过 MCP 检索与沉淀长期记忆。可选：挂载 Cloudflare R2 存储与配置在线提炼模型；其余设置项均自带生产级推荐值，保持默认即可。
⚠️ 未完成配置：请填写下方 MCP Key 与数据库名称，然后点击「一键创建数据库」

路径一 自动记忆 推荐

由网关直接提供对话，不需要开启 Magpie 内置的「记录网关对话」，不占磁盘。开关是 auto_harvest。

路径二 扫描对话录制 备选

读 Magpie 内置录制，需要先在「设置 → 插件 →「会话」」里开启录制（会占用本地磁盘，官方上限 7 天 / 256 MiB）。对应「立即扫描对话录制」按钮。

推荐 关
开启后网关上每次模型交互都会由异步钩子自动提炼事实、架构决策与避坑经验入库，基于在线模型抽取，不占磁盘。
开：网关上每次模型交互都会被提炼入库；关（默认）：关闭自动记忆，关闭则零影响。

📦 备选路径：扫描对话录制（依赖本地磁盘落盘）

若需使用此备选路径扫描本地录制，需先在 Magpie 里开启对话录制：
打开 设置 → 插件，找到内置插件 「会话」 把它打开（开关位于插件页中该插件的说明文字旁）。
打开后该插件会显示 「正在记录网关对话」；其说明文字为 「已开启：Agent 经网关发送的内容和回复只保存在这台电脑上，最多 7 天（256 MiB），可在每个网关会话下查看」。
若要关闭录制，点 「停止记录并清空已保存的对话」。
—— 插件本页只是读取该录制的结果，无法代你开启，需先去那里打开。若使用上方的推荐方案「自动记忆」，则完全无需开启此录制功能。

本地落盘与隐私保护说明：
1. 开启录制意味着对话内容会写到本地磁盘（/config/magpie/gateway-conversations，受官方 7 天 / 256 MiB 配额限制）。
2. 插件只把提炼后的结构化记忆入库，绝不把对话原文入库；提炼采用在线模型抽取。
3. 若未开启录制或暂无录制文件，点击扫描将显示友好提示，不会报错。

确认一键创建数据库

将向宿主提交一键创建信标，自动执行以下操作：

  • 自动在 NoCodeBackend 上创建数据库（若不存在）
  • 自动补齐缺失的数据表（memories、pitfalls、schema_meta）、列与索引
  • 若同名已存在不会破坏数据：将走复用/补齐策略，绝不删除已有数据
  • 不会动 R2 存储（如需挂载 R2，请在下方 R2 卡片单独点击「挂载 R2 存储」）
  • 新建库时自动保存密钥：若本次新建数据库，将保存 NCB 仅在建库时返回一次的 Secret Key；复用已有库则无法读取，须手动填入

将删除 memories / pitfalls / schema_meta 三张表，表结构与全部数据一并删除，不可恢复；库中其它表不受影响。
