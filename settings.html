🧠 记忆中枢与 MCP 控制台 v1.7.0

网关前置无感注入、自定义提炼模型/分组路由、NoCodeBackend 数据库专属 API Key 鉴权与远程 MCP 导出。

1. 网关前置无感注入 (Gateway Interception)

启用记忆自动注入 (Auto-Injection)
拦截用户 Prompt 并在路由前自动注入匹配的架构经验与开发规范
注入避坑警示 (Engineering Pitfalls)
当识别到匹配的技术栈时，自动前置注入历史上记录的故障根因与修复解
版本更替淘汰 (Auto Supersede)
当写入同一主题的新经验时，自动将旧记录标记为 superseded 淘汰

2. 记忆提炼与 Clef 仲裁模型 (Learner & Clef Pipeline) 纯手动输入

对话收尾后自动提炼事实并由判断模型进行质量裁决。支持直接输入单个具体模型 ID 或你在网关路由中配置的组合模型/路由分组别名。

负责从长对话中提取关键知识，推荐填写响应极快的小模型或极速分组
负责裁决事实价值并去重淘汰，如由多个 CF 账号组合成的 group/clef

3. 动态远程 MCP 服务挂载 (Model Context Protocol)

对外暴露标准远程 MCP 端点。支持挂载到 Cursor、Claude Desktop、Cline 或 Minis，Agent 可通过此接口主动检索与沉淀记忆。

动态检测当前访问域名，亦可自定义修改
支持 /41694_agent_core_hub/mcp 或 /memory/mcp
🔐 安全鉴权提示：此端点需要携带 Authorization: Bearer $MAGPIE_API_KEY 请求头（复用 Magpie 网关统一密钥）。
关键参数名 当前配置值 说明
server_name magpie-memory-hub MCP 服务注册唯一标识
mcp_url https://.../mcp 动态检测生成的外网远程端点
headers {"Authorization": "Bearer $MAGPIE_API_KEY"} 复用 Magpie 网关访问密钥鉴权
NCB_INSTANCE 41694_agent_core_hub NoCodeBackend 终态核心数据库实例

4. NoCodeBackend 云端持久层凭据

Magpie 记忆插件与后台引擎通过专属 Secret Key / API Key 直接与 NoCodeBackend 数据库建立安全通信。

NoCodeBackend 上的唯一数据库标识
大文件、架构图与产物 CDN 加速域名
在 NoCodeBackend 数据库菜单中生成的独立 Secret Key，用于插件与数据库专属通信
